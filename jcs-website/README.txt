FREE PUBLISHING VIA GITHUB PAGES
1. Create a free account at https://github.com
2. Create a new PUBLIC repository, e.g. jcs-tires-website.
3. Upload index.html from this folder to the repository root and commit.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch; branch main; folder / (root); Save.
6. Wait for the Pages site to deploy. GitHub will display your public website URL, usually https://USERNAME.github.io/jcs-tires-website/
7. Test on a phone: Call Now, Get Directions, and Request a Quote.

QUOTE FORM
This version uses the customer's SMS app, with a prefilled message to 980-415-8907. The customer MUST press Send. There is no server, no database, and no paid backend. SMS URL behavior varies by browser/device; test it on your customers' common devices. If it does not open, they can always use Call Now. If you later want a form that sends silently, you will need a separate form service or backend.

BEFORE GOING LIVE
- Confirm address, phone number, services and the $45 used tire promotion.
- Add business hours when known (none are shown because none were provided).
- Add your logo and real shop photos if desired.
- Verify that roadside assistance is available in your service area.
- Consider buying a custom domain later; free GitHub Pages URL works without one.

EDITING
Open index.html in any text editor. Search for the text you want to change, save, and upload the revised file to GitHub.
